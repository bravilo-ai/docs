## Agente

Un **Agente** es un asistente de IA entrenado con la información de tu negocio. Los agentes pueden responder preguntas, recolectar datos, ejecutar acciones y conversar por múltiples canales.

Cada agente tiene:
- **Instrucciones**: Cómo debe comportarse (prompt de sistema).
- **Base de conocimiento**: Documentos, URLs y archivos que usa para responder.
- **Herramientas**: Acciones que puede ejecutar (formularios, calendarios, webhooks).
- **Canales**: Dónde conversa (web, WhatsApp, Instagram, etc.).

## Almacén de datos (Datastore)

Un **Datastore** es una colección de documentos que alimenta la base de conocimiento de un agente. Soporta:
- URLs web (con scraping automático).
- Archivos (PDF, DOCX, TXT, etc.).
- Integraciones (Google Drive, Notion).
- Inserción vía API (para sistemas externos).

## Formulario

Un **Formulario** es una secuencia de preguntas que el agente puede hacer al usuario de forma conversacional. Los resultados se guardan como leads o se envían por webhook.

## Conversación

Una **Conversación** es el historial de mensajes entre un usuario y un agente. Incluye metadata como canal, origen, calificaciones y estado.

## Widget

Un **Widget** es la interfaz de chat que se embebe en tu sitio web. Es completamente personalizable: colores, posición, avatar y sugerencias de mensajes.

## Integración

Una **Integración** es una conexión con servicios externos: WhatsApp Business API, Instagram, Google Calendar, Zapier, etc.
