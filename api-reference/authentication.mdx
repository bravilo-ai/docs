## ¿Qué es una API Key?

Una API Key es una clave secreta que te permite conectar Bravilo con otros sistemas de forma programática.

Es como un "password" que identifica a tu organización.

Integraciones custom Conectá Bravilo con tu CRM, ERP o cualquier sistema propio.

Acceso seguro Cada request se autentica con tu key.

Solo tu organización puede acceder.

## Crear una API Key

Para generar tu primera API Key: \- Andá a Configuración → "API Keys"
- Hacé click en "Crear API Key"
- Tu nueva key aparece en la lista
- Hacé click sobre la key para copiarla al portapapeles

## Usar tu API Key

Incluí tu API Key en las requests HTTP usando el header Authorization : Documentación completa: Visitá docs.braviloai.com para ver todos los endpoints disponibles, ejemplos y SDKs.

## Gestionar API Keys

Podés tener múltiples API Keys activas y eliminar las que ya no necesitás: Crear múltiples Creá keys separadas para cada integración (una para tu CRM, otra para webhooks, etc.).

Eliminar Hacé click en el ícono de papelera junto a la key.

Debés tener al menos una key activa.

Cuidado: Si eliminás una key que está siendo usada por una integración, esa integración dejará de funcionar inmediatamente.

Asegurate de actualizar la key en tu sistema antes de eliminar la anterior.
