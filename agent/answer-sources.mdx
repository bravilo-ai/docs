---
title: "Fuentes de Respuesta"
description: "Mostrá de dónde saca la información el agente"
---

Las **Fuentes de Respuesta** son enlaces a los documentos o fragmentos de datastore que el agente usó para generar una respuesta.

## Cómo funciona

Cuando el agente responde usando información de tu base de conocimiento, puede mostrar al usuario las fuentes exactas (nombre del documento y link).

## Activación

1. Andá a tu agente → **Configuración**
2. Buscá la opción **"Incluir fuentes"**
3. Activá el toggle

## Qué se muestra

- **Nombre del datasource**: "Política de Privacidad", "Catálogo 2024", etc.
- **Link directo**: Si el datasource tiene una URL pública, el usuario puede hacer click.
- **Score de relevancia**: Qué tan relacionado estaba el fragmento con la pregunta.

## Cuándo usarlo

- **Soporte técnico**: El usuario puede verificar la info en la documentación original.
- **Legal/compliance**: Demostrá que la respuesta se basa en documentos oficiales.
- **Transparencia**: Generá confianza mostrando de dónde viene cada dato.

## Consejos

- Si las fuentes son internas o privadas, desactivá esta opción.
- Mantené los nombres de los datasources descriptivos para que el usuario entienda qué está viendo.
