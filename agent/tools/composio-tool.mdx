La **Composio Tool** habilita el catálogo completo de herramientas de [Composio](https://composio.dev), permitiendo que tu agente se conecte y ejecute acciones en cientos de aplicaciones SaaS.

## Qué puede hacer

- **Notion**: Crear páginas, consultar bases de datos, actualizar registros.
- **GitHub**: Crear issues, hacer code review, mergear PRs.
- **CRM**: Salesforce, HubSpot, Pipedrive.
- **Y muchas más**: Google Docs, Trello, Asana, Jira, etc.

## Configuración

1. Andá a tu agente → **Habilidades**
2. Buscá **"Composio"**
3. Conectá tu cuenta de Composio (o creá una nueva)
4. Seleccioná las apps que querés habilitar para el agente
5. Autorizá cada app individualmente (OAuth)

## Ejemplo de uso

> Usuario: "Creá una página en Notion para el proyecto Alpha"
> Agente: "Listo, creé la página 'Proyecto Alpha' en tu workspace de Notion."

## Requisitos

- Cuenta en Composio (puede ser gratuita).
- Autorización OAuth para cada app que querés usar.

## Limitaciones

- Algunas apps requieren plan pago de Composio.
- El agente solo puede hacer acciones que estén disponibles en el plan de Composio vinculado.
