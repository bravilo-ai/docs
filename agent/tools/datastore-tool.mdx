---

El **Datastore Tool** permite que tu agente consulte información de una base de conocimiento durante una conversación.

## Cómo funciona

Cuando un usuario hace una pregunta, el agente busca en el datastore los fragmentos de documentos más relevantes y usa esa información para responder con precisión.

## Configuración

1. Andá a tu agente → **Habilidades**
2. Hacé click en **"Agregar Datastore"**
3. Seleccioná el datastore que querés conectar
4. Definí cuántos fragmentos (chunks) querés que recupere el agente por consulta

## Casos de uso

- **Soporte técnico**: El agente consulta manuales y FAQs para responder dudas.
- **Ventas**: Consulta catálogos de productos, precios y disponibilidad.
- **Onboarding**: Busca en guías internas para ayudar a nuevos empleados.

## Consejos

- Mantené el datastore actualizado con información fresca.
- Usá metadata para filtrar resultados por categoría, producto o departamento.
- Si el agente no encuentra respuesta, configurá un mensaje de fallback claro.
