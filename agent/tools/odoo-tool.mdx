---
title: "Odoo Tool"
description: "Integrá tu agente con Odoo para gestionar ventas, stock y CRM"
---

La **Odoo Tool** permite que tu agente interactúe con tu instancia de Odoo para consultar datos, crear registros y gestionar procesos de negocio.

## Qué puede hacer

- **Consultar productos**: Verificar stock, precios y descripciones.
- **Crear oportunidades**: Generar leads en el CRM de Odoo.
- **Consultar pedidos**: Buscar órdenes de venta y su estado.

## Configuración

1. Andá a tu agente → **Habilidades**
2. Buscá **"Odoo"**
3. Configurá la URL de tu instancia de Odoo y las credenciales de API
4. Definí qué modelos puede consultar el agente (productos, leads, órdenes)

## Ejemplo de uso

> Usuario: "¿Cuánto cuesta el producto SKU-1234?"
> Agente: "El producto SKU-1234 cuesta $12.500 y tenemos 15 unidades en stock."

## Requisitos

- Instancia de Odoo (Community o Enterprise).
- Usuario de API con permisos de lectura/escritura sobre los modelos necesarios.

## Solución de problemas

- **Error de conexión**: Verificá que la URL de Odoo sea accesible desde internet y que el usuario de API esté activo.
