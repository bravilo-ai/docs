---

La **Enviar Archivos Tool** permite que tu agente envíe documentos (PDF, Excel, CSV, imágenes, videos) a través de WhatsApp y otros canales de mensajería.

## Qué puede hacer

- **Enviar PDFs**: Catálogos, facturas, manuales.
- **Enviar imágenes**: Fotos de productos, capturas de pantalla.
- **Enviar Excel/CSV**: Reportes, listas de precios.
- **Enviar videos**: Tutoriales, demos.

## Configuración

1. Andá a tu agente → **Habilidades**
2. Buscá **"Enviar Archivos"**
3. Subí los archivos que el agente podrá enviar (o indicá URLs públicas)
4. Asigná un nombre descriptivo a cada archivo para que el agente sepa cuándo usarlo

## Ejemplo de uso

> Usuario: "¿Podés enviarme el catálogo de productos?"
> Agente: "Claro, te envío el catálogo por WhatsApp."
> *[Envía catalogo-2024.pdf]*

## Canales soportados

- WhatsApp Business API
- Instagram DM
- Facebook Messenger

## Buenas prácticas

- Mantené los archivos actualizados. El agente no sabe si un archivo está desactualizado.
- Usá nombres claros: "catálogo-2024.pdf" en vez de "doc1.pdf".
- Verificá los límites de tamaño de cada canal (WhatsApp: 100MB para documentos).
