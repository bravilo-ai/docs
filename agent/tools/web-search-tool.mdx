---
title: "Buscador Web Tool"
description: "Permití que tu agente busque información en internet"
---

La **Buscador Web Tool** permite que tu agente busque información actualizada en internet y la use para responder preguntas.

## Qué puede hacer

- **Buscar noticias**: Información actual sobre cualquier tema.
- **Consultar precios**: Precios de competidores o productos.
- **Verificar datos**: Confirmar información que no está en tu base de conocimiento.
- **Investigar**: Encontrar artículos, estudios o documentación.

## Configuración

1. Andá a tu agente → **Habilidades**
2. Buscá **"Buscador Web"**
3. Activá la herramienta
4. Opcional: Limitá los dominios que puede consultar (whitelist/blacklist)

## Ejemplo de uso

> Usuario: "¿Cuál es el tipo de cambio del dólar hoy?"
> Agente: "Hoy el dólar blue está a $1.245 y el dólar oficial a $925."

## Requisitos

- Tu agente debe tener activada la capacidad de ejecutar herramientas externas.
- Si esta capacidad no está disponible en tu plan, la herramienta no funcionará.

## Consejos

- Usá esta herramienta para datos que cambian frecuentemente. Para información estable, preferí cargarla en un datastore.
- Configurá un límite de búsquedas por conversación para controlar costos.
