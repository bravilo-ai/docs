El **Chat de Sitio** es un agente de IA entrenado con la información de tu negocio para responder preguntas de clientes directamente desde tu web.

## Características

- **Entrenamiento automático**: Indexa tu sitio web, documentos y FAQs.
- **Widget embebible**: Se integra en cualquier página con un script.
- **Respuestas instantáneas**: Reduce tiempos de espera al mínimo.
- **Escalación humana**: Pasa a un agente humano cuando sea necesario.

## Cómo empezar

1. Creá un agente en el [Dashboard](https://braviloai.com).
2. Agregá datasources (URL de tu web, documentos PDF, etc.).
3. Configurá el widget (colores, posición, avatar).
4. Copiá el código de embed y pegalo en tu sitio.

## Diferencia con WhatsApp/Instagram

| Característica | Chat de Sitio | WhatsApp/Instagram |
|----------------|---------------|--------------------|
| Requiere cuenta de usuario | No | Sí |
| Disponibilidad 24/7 | Sí | Sí |
| Multimedios | Texto, links | Texto, imágenes, audio, documentos |
| Costo por mensaje | Solo API de IA | API de IA + API del canal |
