# Centro de Ayuda de Bravilo

Guías paso a paso para sacar el máximo provecho de Bravilo. Aprendé a configurar agentes, conectar canales y automatizar tu atención al cliente con IA.

## Primeros pasos

### Tu primer agente en 5 minutos
Creá tu primer agente de IA describiendo lo que necesitás. Bravilo genera todo automáticamente.

### Probar tu agente antes de publicar
Usá el playground interno para verificar respuestas, ajustar el prompt y asegurarte que funcione perfecto.

## Canales

### Conectar WhatsApp Business
Conectá tu WhatsApp Business oficial. Coexistencia con la app del celular incluida.

### Conectar Instagram
Conectá tu cuenta de Instagram Business para responder DMs, stories y comentarios con IA.

### Instalar chat en tu web
Agregá el widget de chat a cualquier sitio web con una sola línea de código. Personalizable al 100%.

### Conectar otros canales
Guía para conectar Telegram, MercadoLibre, Email y más canales disponibles.

## Herramientas

### Google Calendar: Agendar citas
Conectá Google Calendar para que tu agente agende citas automáticamente vía conversación.

### Google Sheets: Leer y escribir datos
Conectá una planilla de Google Sheets para que tu agente pueda leer y guardar datos en tiempo real.

### Webhooks y HTTP Tools
Dos integraciones: HTTP Tools para acciones durante conversaciones, y Webhooks para notificaciones automáticas.

## CRM y Leads

### Contactos y listas
Importá contactos desde CSV, segmentá con tags y creá listas para campañas.

### Campañas de broadcast
Creá campañas masivas: templates de mensaje, programación y tracking de resultados.

### Lead Prospector
Encontrá empresas y contactos ideales para tu negocio, segmentá y armá listas de outreach.

## Avanzado

### Multi-agente: Triggers y routing
Cuándo y cómo usar múltiples agentes con triggers por keyword, intent o horario.

### Equipo: Invitar colaboradores
Invitá miembros a tu organización, asigná roles y permisos por sección.

### API Keys y uso programático
Generá API keys, scopes de permisos y ejemplos de uso para integraciones custom.
