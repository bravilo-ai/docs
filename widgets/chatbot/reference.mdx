El Chatbot está disponible a través de nuestro CDN como un archivo JavaScript único o a través de NPM como un paquete de componente React.

<Tabs>
<Tab title="HTML" >
```html
<script type="module">
import Chatbox from 'https://cdn.jsdelivr.net/npm/@bravilohq/embeds@latest/dist/chatbox/index.js';

Chatbox.initBubble({
agentId: 'TU_AGENT_ID',
});

</script>

````
</Tab>
<Tab title="React" >
```jsx
import { Chatbox } from '@bravilohq/embeds';

function App() {
return (
<Chatbox
agentId="TU_AGENT_ID"
contact={{
firstName: 'John',
lastName: 'Doe',
email: 'customer@email.com',
phoneNumber: '+33612345644',
userId: '42424242',
initialMessages={[
'Hola Georges, ¿cómo estás hoy?',
'¿Cómo puedo ayudarte?',
]}
context="El usuario con quien estás hablando es John. Comienza saludándolo por su nombre."
/>
);
```
</Tab>
</Tabs>

## Atributos / Props

<Tabs>
<Tab title="HTML" >
```html
<script type="module">
import Chatbox from 'https://cdn.jsdelivr.net/npm/@bravilohq/embeds@latest/dist/chatbox/index.js';

Chatbox.initBubble({
agentId: 'TU_AGENT_ID',

// Si se proporciona creará un contacto para el usuario y lo vinculará a la conversación
contact: {
firstName: 'John',
lastName: 'Doe',
email: 'customer@email.com',
phoneNumber: '+33612345644',
userId: '42424242',
},
// Sobrescribir mensajes iniciales
initialMessages: [
'Hola Georges, ¿cómo estás hoy?',
'¿Cómo puedo ayudarte?',
],
// El contexto proporcionado se agregará al prompt del sistema del Agente
context: "El usuario con quien estás hablando es John. Comienza saludándolo por su nombre.",

});

</script>
```
</Tab>

## Métodos

<ParamField path="open" type="solo widget de burbuja">
Abrir Chatbox de Burbuja
```js
const widget = await Chatbox.initBubble({
agentId: 'TU_AGENT_ID',
widget.open()

````

</ParamField>

<ParamField path="close" type="solo widget de burbuja">
Cerrar Chatbox de Burbuja
```js
const widget = await Chatbox.initBubble({
agentId: 'TU_AGENT_ID',
widget.close()

````

</ParamField>

<ParamField path="toggle" type="solo widget de burbuja">

```js Alternar Chatbox de Burbuja
const widget = await Chatbox.initBubble({
agentId: 'TU_AGENT_ID',
widget.toggle()
````

</ParamField>

<ParamField path="createNewConversation" >

const widget = await Chatbox.initBubble({
