## Obtener el ID de tu agente

Cada agente tiene un ID único que necesitás para generar el código del widget.

Para encontrarlo: \- Andá a Agentes en el menú lateral
- Hacé click en el agente que querés instalar
- Buscá la pestaña "Apps"
- En la sección "Chat Bubble" , vas a ver el snippet con tu ID ya incluido

## Copiar el código del widget

Copiá este fragmento de código y pegalo justo antes del cierre de en tu sitio web: `\} /> Reemplazá TU_AGENT_ID_AQUÍ con el ID de tu agente (el que copiaste en el paso anterior).

Mejor opción: Usá directamente el snippet que aparece en la pestaña "Apps" del agente — ya viene con tu ID configurado.
