---
title: 'Burbuja'
description: 'Instalar en tu sitio web'
---

Para instalar un Agente en tu sitio web usando el widget de Burbuja usá el siguiente fragmento de código:

```html
<script type="module">
import Chatbox from 'https://cdn.jsdelivr.net/npm/@bravilohq/embeds@latest/dist/chatbox/index.js';

Chatbox.initBubble({
agentId: 'TU_AGENT_ID',
});
</script>
```

Reemplaza `TU_AGENT_ID` con el ID de tu Agente

<Note>
Podés encontrar el ID del Agente en la configuración del Agente bajo la pestaña
de Configuración.
</Note>

Ve todos los atributos disponibles en la [Referencia del Chatbot](/widgets/chatbot/reference).
